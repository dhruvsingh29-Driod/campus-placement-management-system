# Contributing to Campus Placement Management System

Contributions to enhance features, security, and UI capabilities are welcome!

## Getting Started

1. **Fork & Clone**
   ```bash
   git clone https://github.com/<your-username>/campus-placement-management-system.git
   cd campus-placement-management-system
   ```

2. **Install Dependencies**
   ```bash
   npm install
   ```

3. **Run Automated Tests**
   ```bash
   npm test
   ```

4. **Start Development Server**
   ```bash
   npm start
   ```

5. **Commit Conventions**
   - `feat:` for new capabilities
   - `fix:` for bug fixes
   - `test:` for test additions
   - `docs:` for documentation
